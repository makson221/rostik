# Завдання №1 — Лікарня

## 1. Предметна область

**Лікарня** — облік медичного персоналу, пацієнтів та структурних підрозділів.

## 2. Основні сутності

1. **Лікар**
2. **Пацієнт**
3. **Відділення**

## 3. Характеристики сутностей

### Лікар
- № (ідентифікатор)
- ПІБ
- Спеціалізація
- Відділення
- Кваліфікаційна категорія
- Стаж (років)
- Кабінет
- Телефон
- Ставка (грн)

### Пацієнт
- № медичної картки
- ПІБ
- Дата народження
- Стать
- Адреса
- Телефон
- Діагноз
- Лікуючий лікар
- Дата госпіталізації
- Палата

### Відділення
- Код
- Назва
- Завідувач
- Поверх
- Кількість ліжок
- Вільних ліжок
- Кількість лікарів
- Години прийому
- Внутрішній телефон

## 4. HTML-сторінка

Файл [`index.html`](index.html) містить три таблиці (по одній на кожну сутність),
які фізично знаходяться на одній сторінці. Користувач перемикається між ними
за допомогою табів «Лікарі», «Пацієнти», «Відділення».

Щоб переглянути — відкрийте `index.html` у браузері.
