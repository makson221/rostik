# Завдання №1 — Лікарня

## 1. Предметна область

**Лікарня** — облік медичного персоналу, пацієнтів та структурних підрозділів.

## 2. Основні сутності

1. **Лікар**
2. **Пацієнт**
3. **Відділення**

## 3. Характеристики сутностей

### Лікар
- № (ідентифікатор)
- ПІБ
- Спеціалізація
- Відділення
- Кваліфікаційна категорія
- Стаж (років)
- Кабінет
- Телефон
- Ставка (грн)

### Пацієнт
- № медичної картки
- ПІБ
- Дата народження
- Стать
- Адреса
- Телефон
- Діагноз
- Лікуючий лікар
- Дата госпіталізації
- Палата

### Відділення
- Код
- Назва
- Завідувач
- Поверх
- Кількість ліжок
- Вільних ліжок
- Кількість лікарів
- Години прийому
- Внутрішній телефон

## 4. HTML-сторінка

Файл [`index.html`](index.html) містить три таблиці (по одній на кожну сутність),
які заповнюються за допомогою JavaScript ([`script.js`](script.js)): дані зберігаються
в масивах об'єктів, а функція `renderTable()` будує з них рядки таблиць. Таблиці
фізично знаходяться на одній сторінці. Користувач перемикається між ними
за допомогою табів «Лікарі», «Пацієнти», «Відділення».

Щоб переглянути — відкрийте `index.html` у браузері.

# Завдання №2 — Форма додавання даних

На кожному табі є кнопка **«+ Додати …»** (лікаря / пацієнта / відділення).
Вона відкриває попап (`<dialog>`) з формою. Поля форми генеруються в `script.js`
з того самого опису колонок, що й таблиця, тому структура форми завжди збігається
зі структурою сутності.

- **Типи полів:** текст, число, дата (`<input type="date">`), телефон, випадаючий
  список (категорія, стать, відділення). Для деяких полів є підказки з уже
  наявних значень (`<datalist>`): спеціалізація, діагноз, лікуючий лікар, завідувач.
- **Автоматичні поля:** № лікаря і № картки пацієнта (`P-1006`, …) генеруються самі.
- **Перевірки:**
  - усі поля обов'язкові;
  - числа мають бути цілими й у допустимих межах;
  - формат телефону, кабінету, коду відділення;
  - дата народження не в майбутньому, дата госпіталізації не раніше народження;
  - код і назва відділення унікальні, а вільних ліжок не більше, ніж усього ліжок.

  Помилки показуються під відповідним полем.
- Після збереження запис додається в масив, таблиця перемальовується, новий
  рядок коротко підсвічується. Попап закривається кнопками «×», «Скасувати»,
  клавішею Esc або кліком поза ним.

Починаючи із завдання №4, нові записи зберігаються в localStorage (див. нижче).

# Завдання №3 — Видалення та зміна даних

### Зв'язки між таблицями
Таблиці пов'язані через ключі (а не через текст):

| Таблиця | Поле | Посилається на |
|---|---|---|
| Лікарі | Відділення | Відділення (код) |
| Пацієнти | Лікуючий лікар | Лікарі (№) |
| Відділення | Завідувач | Лікарі (№) |

У таблиці показується назва / ПІБ зі зв'язаної таблиці, тому якщо змінити, наприклад,
ПІБ лікаря, воно одразу оновиться в таблицях «Пацієнти» та «Відділення».

### Видалення
- У кожному рядку справа є хрестик **×**.
- Якщо запис використовується в іншій таблиці (лікар закріплений за пацієнтом або є
  завідувачем, у відділенні працюють лікарі), з'являється попап **«Видалення неможливе»**
  зі списком записів, де він використовується.
- Інакше з'являється попап підтвердження, і після нього рядок видаляється.

### Зміна даних
- Клік по комірці: замість тексту з'являється поле вводу відповідного типу (текст, число,
  дата або випадний список).
- **Enter** або кнопка **✓** — зберегти. Якщо значення некоректне, під полем
  з'являється помилка, і поле лишається відкритим.
- **Клік у будь-якому іншому місці** — зберегти. Некоректна зміна в цьому випадку скасовується.
- **Esc** — скасувати.
- Перевірки ті самі, що й у формі додавання.
- Ключові поля (№ лікаря, № картки, код відділення) не змінюються.

# Завдання №4 — Збереження та синхронізація

1. Усі зміни (додавання, редагування, видалення) зберігаються в **localStorage**
   (ключ `hospital-db-v1`).
2. Під час повторного відкриття сторінки дані завантажуються з localStorage. Якщо
   збережених даних немає, показуються початкові.
3. Якщо відкрито кілька вкладок зі сторінкою, зміна в одній автоматично з'являється
   в усіх інших. Для цього використовується подія `storage`. Якщо в іншій вкладці відкрита
   форма додавання, її випадні списки теж оновлюються.
4. **Поля-списки з прив'язкою до іншої таблиці** (без ручного введення):
   - Лікар → *Відділення* — список відділень із таблиці «Відділення»;
   - Пацієнт → *Лікуючий лікар* — список лікарів із таблиці «Лікарі»;
   - Відділення → *Завідувач* — список лікарів із таблиці «Лікарі».

   Списки працюють і у формі додавання, і під час редагування комірки. Нове відділення
   чи лікар одразу з'являються в цих списках.

Кнопка **«Відновити початкові дані»** внизу сторінки повертає все до початкового стану.
